# Агентский поиск по тематическим коллажам

Коллажи предназначены только для первичного поиска (`DISCOVERY_ONLY`). Они не являются исходными референсами для генерации, не задают стиль или личность, не подтверждают совместимость и не создают одобрение.

1. Сначала найди страницу командой `python tools/build_shape_fit_collages.py find --topic mouth --subject NEUTRAL` (или другую тему/метку). Не читай целиком большой индекс для простой выборки. Перечень тем — `TOPICS.md`; `INDEX.json` хранит полное соответствие. Отфильтруй записи по нужной подтеме и точной метке субъекта (`MALE`, `FEMALE` или `NEUTRAL`) до открытия изображения. Не используй коллаж другой метки как запасной вариант.
2. Открой только одну подходящую страницу коллажа и найди нужную ячейку. Индекс связывает ячейку с исходным ID, путём и SHA-256. Номер ячейки не является ID референса.
3. По INDEX выбери точный исходный single: сверяй ID, относительный путь и хеш с текущим `SINGLES_MANIFEST.json`. Если запись или хеш изменились, не используй найденную ячейку.
4. Просмотри в полном разрешении только выбранный исходный single; проверь, что он соответствует запросу, нужной области и роли, и что метка пола подтверждена и совпадает с целью. Коллаж не заменяет эту проверку.
5. Выбери single штатным `reference_pool_manager select` с точными `--id`, `--role`, `--subject` и явным `--variant`, затем передай его через штатную подготовку запроса. Передай выполненную проверку текущему запросу; не повторяй неизменённый просмотр.

Коллажи нельзя прикреплять к генератору, использовать как стилевой или идентификационный источник, считать одобренными или использовать для изменения профиля. `NEUTRAL` остаётся отдельной меткой: она сама по себе не разрешает переносить схему на мужскую или женскую анатомию и никогда не расширяет допуск sex-specific поз. Неизвестный, смешанный или неподтверждённый субъект не заменяется нейтральной меткой.

После выбора ячейки: `python tools/build_shape_fit_collages.py find --topic mouth --subject NEUTRAL --cell 13`. Команда возвращает точный ID, путь, variant и SHA256. Она проверяет актуальность индекса по хешу manifest. Если индекс устарел, пересобери `python tools/build_shape_fit_collages.py build`. Пути в индексе считаются относительно SODABABYX_SOURCE_COLLECTION.
