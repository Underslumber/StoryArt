# WaveSpeed — каталог поз StoryArt

491 поза × 3 ракурса (front / three_quarter / side) × 2 представления
(3d / line) = 2946 оригинальных WebP 900×1200. Источник —
[WaveSpeed AI Pose Gallery](https://wavespeed.ai/free-tools/ai-pose-gallery).
Изображения сохраняются без ретуши, обрезки и перекодирования.

Это основной каталог **поиска поз**, дополнительный к существующим источникам
StoryArt. Он не заменяет утверждённые лицо, тело, одежду и STYLE персонажа.
Выбор необязательной позы по-прежнему только по запросу автора.

Изображения и переносимая разметка поставляются с Git checkout StoryArt.
При неполной копии штатный `reference_packs install WAVESPEED_POSES` получает
недостающие файлы непосредственно с GitHub StoryArt и проверяет SHA-256.
Загрузка с WaveSpeed при обычной установке не нужна.

`POSES.json` связывает каждый оригинал с источником, группой, ракурсом,
представлением, категорией, размером и SHA-256. Пол и видимая анатомия проверены
отдельно для каждого изображения; метки не наследуются между ракурсами.

Все 2946 оригиналов проверены индивидуально: **готовых — 2885, исключённых — 61**; готовые источники охватывают 490 групп поз.

В обычный поиск и выбор попадает `curation_status=READY` с индивидуальным PASS
видимой взаимосвязанной позы. Подтверждённая нейтральная схема `NEUTRAL`
подходит для мужского и женского персонажа. Парные позы `MIXED` разрешены для
сцен с несколькими персонажами: у каждого участника есть собственные
`participant_id`, `subject_label`, видимая привязка `locator`, свидетельство и
хеш оригинала. Нейтральный участник также подходит обоим полам. Неопределённый
`UNKNOWN` ожидает выбора автора; все 11 анатомических отказов сохранены.
Разметка участников охватывает все 360 парных изображений; 331 уже готовы.
Все исходники сохранены без изменений для аудита; причина есть в
`curation_reason`, наблюдения и ограничения — в `visual_review_evidence` и
`review_limitations`. `SUBJECT_REVIEWS.json` содержит полный журнал всех 2946
проверок с точными хешами. Отсутствующий или устаревший допуск блокирует выбор.

После скачивания повторная первичная классификация готовой части не требуется.
Автор завершил разметку: все 494 поля для 411 изображений обработаны,
неразобранных случаев больше нет. Исключены 52 изображения по решению автора
и 11 по анатомии; два входят в обе группы, всего 61. Исходники сохранены.
Явно исключённые автором источники не предлагаются повторно для классификации.
Допуск относится к видимой крупной позе, опорам и камере. Скрытые суставы и
пальцы не дорисованы предположением; это не атлас тонкой анатомии кистей.
Для обрезанных кадров `UPPER_BODY_ONLY` запрещает выводить ноги, таз, стойку
или опоры вне кадра. Указанные в каждой записи стул, пол, стену и другие
необходимые опоры нужно сохранить при переносе. Пригодность выбранной позы
для конкретной сцены, identity/STYLE и физическое вложение проверяются штатно.

Штатные команды из корня StoryArt:

```powershell
.\scripts\storyart.ps1 reference_packs verify WAVESPEED_POSES
```

```powershell
.\scripts\storyart.ps1 reference_pool_manager search --pool WAVESPEED_POSES --query Standing
```

Выбор готового источника при совпадении пола:

```powershell
.\scripts\storyart.ps1 reference_pool_manager select --pool WAVESPEED_POSES --id WS_0001_3d_front --role AUX_POSE --subject MALE --output work/pose-selection.json
```

Пример использует индивидуально проверенный мужской источник; для женского
персонажа он запрещён. Подготовка конкретного вызова принимает
`--pose-pool-reference ID=AUX_POSE` или `ID=AUX_CAMERA`; все обычные проверки
плана, физического вложения, риска и результата сохраняются. Перед исполнением
повторно проверяются текущие байты и привязка разметки.

Для обновления проверенной разметки менеджер принимает
`wavespeed_pose_library --apply-reviews-only --review-file <JSON> --require-complete-curation`.
Каждая запись `reviews` содержит `id`, точный `sha256`, `reviewer`,
`subject_label` и `subject_label_evidence`. Отдельные `visual_qa_status` и
`anatomy_qa_status` могут быть `NOT_CHECKED`, `FAIL`, `PASS`.
Для PASS нужны `viewed=FULL_RESOLUTION`, `visual_review_evidence` и
`review_limitations`. NEUTRAL разрешён обоим полам; MIXED требует полной
разметки участников, UNKNOWN ожидает решения автора.
Право первичного просмотра для классификации регулируется правилами проекта.
Для завершённого набора обязательны `review_complete=true`, `curation_status=READY/EXCLUDED`
и причина. Флаг `--require-complete-curation` проверяет полноту всех 2946
оригиналов, включая исключённые. После обновления пересобрать пакет и базу поиска.

Front / Side / 3/4 — названия камеры издателя, а не анатомическая сторона тела:
на изображении Front фигура может быть обращена спиной к камере.
Три угла — связанные издателем изображения одной позы, а не доказательство
тождественности 3D-скелета. Перед использованием проверять тело целиком,
суставы, таз/торс, голову, опоры, равновесие, проекцию и видимые руки.

Условия автора: [TERMS.md](TERMS.md).

## Парные позы и авторская классификация

Привязка парной позы при подготовке вызова:

```powershell
.\scripts\storyart.ps1 style_pack_manager prepare-generation <остальные параметры> --pose-pool-reference "WS_0187_3d_front=AUX_POSE@A:CHAR_001:MALE,B:CHAR_002:FEMALE"
```

После `@` каждый элемент задаёт `источник:персонаж_сцены:пол`. A/B относятся
к видимым привязкам именно выбранного изображения. Все участники должны быть
перечислены по одному, пол проверяется отдельно. Текущий персонаж и его
подтверждённый пол должны присутствовать в привязке. Метки позы не утверждают
личности: identity и одежда каждого персонажа задаются штатным сценарием.
Привязки входят в исполняемый промпт, вложение и повторную exact-call проверку.
CLI `reference_pool_manager select` принимает ту же явную привязку списком
JSON через `--participants-json` (source_participant, scene_participant,
target_subject). Поиск с фильтром MALE/FEMALE также включает нейтральные позы
и подходящих участников парных источников.

Галерея выбора запускается агентом, не требует размещать файлы вручную:

```powershell
.\scripts\storyart.ps1 wavespeed_pose_review serve
```

Выбор сохраняется автоматически в `AUTHOR_CHOICES.json` внутри рабочей папки.
Есть просмотр оригинала, фильтры, отдельные поля A/B и экспорт ответов.
Завершённый автором набор включал все прежние 315 UNKNOWN и новые случаи
участников: 411 изображений / 494 поля выбора, сгруппированные в 199 поз.
Решения применены к точным исходникам; на новом checkout этот набор не
запрашивается повторно. Для будущих новых случаев автор нажимает
«Завершить разметку»; затем агент применяет сохранённые ответы штатной командой:

```powershell
.\scripts\storyart.ps1 wavespeed_pose_review apply
```

Импорт проверяет ID, точные хеши, допустимые значения и полноту ответов.
Выбор пола не снимает анатомический FAIL. Агент пересобирает пакет и базу
поиска и публикует обновление после применения реальных авторских решений.
