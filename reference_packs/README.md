# Reference packs

Каталоги необязательных пулов референсов. В Git лежат только условия
источника, список файлов с SHA-256 и ссылкой на оригинал (`files.csv`) и
разметка StoryArt (`metadata/`). Сами изображения в репозиторий не
попадают. Атлас поз загружается из отдельного закрытого хранилища проекта
в Gitea; остальные пулы — по ссылкам своих источников. Происхождение и
условия авторов сохраняются независимо от места хранения.

```powershell
# Какие пулы есть и что уже установлено.
.\scripts\storyart.ps1 reference_packs list
# Скачать ВЕСЬ атлас: все 1439 PNG из закрытой Gitea в BODY_REFERENCE_LIBRARY/POSE_ATLAS.
.\scripts\storyart.ps1 reference_packs install POSE_ATLAS
# Взять файлы из своей копии вместо скачивания (совпадение проверяется по хешу).
.\scripts\storyart.ps1 reference_packs install POSE_ATLAS --from-dir D:\backup\pose_atlas
# Проверить хеши установленных файлов.
.\scripts\storyart.ps1 reference_packs verify
```

Файл принимается только при совпадении SHA-256. Если оригинал изменился или
пропал, `install` сообщает `HASH_MISMATCH` или `NO_SOURCE` и ничего не
подменяет. Разметка из `metadata/` копируется в пул, если локальной копии нет
или она совпадает; изменённая локальная разметка сохраняется
(`--overwrite-metadata` заменяет её).

## Весь атлас поз одной командой

```powershell
.\scripts\storyart.ps1 reference_packs install POSE_ATLAS
```

Команда получает **все 1439 PNG / 288 поз** из
[StoryArt-Pose-Atlas](https://gitea.xapct.ru/Hatzy/StoryArt-Pose-Atlas).
Выбирать ракурсы или скачивать их по одному не нужно. Изображения занимают
около **638 МиБ**. Загрузка идёт потоком через `git archive`: полная Git-копия
и большой ZIP/TAR на локальном диске не создаются, временно записывается
только очередной PNG. Уже установленные файлы с правильным размером и
SHA-256 сохраняются; повторный запуск полностью установленного пула не
обращается к сети. При обрыве проверенные файлы остаются для повторного запуска.

Нужны Git, OpenSSH и SSH-ключ учётной записи с доступом к закрытому
репозиторию. Пароли, токены и новые права команда не создаёт. Используются
обычные настройки SSH или `GIT_SSH_COMMAND`. Настройки конкретной машины
можно сохранить в исключённом из Git `.local/reference-packs.json`:

```json
{
  "git_ssh_commands": {
    "ssh://git@gitea.xapct.ru:2222/Hatzy/StoryArt-Pose-Atlas.git": "ssh -i <путь-к-своему-ключу> -o IdentitiesOnly=yes -o BatchMode=yes -o StrictHostKeyChecking=yes"
  }
}
```

Агент проверяет существующий SSH-доступ и настраивает локальный маршрут,
не меняя права хранилища и не помещая личные настройки в поставку проекта.
Если доступа нет, загрузка сообщает `INCOMPLETE` / `DOWNLOAD_FAILED`; перехода
на публичное зеркало или запроса административного пароля нет. Результат
`INSTALLED` означает получение всего пула. Разметка субъекта и визуальные
допуски при скачивании не меняются.

Для архива задан общий тайм-аут 1800 секунд; при необходимости он меняется
аргументом `--timeout`. Ветка `main` используется из-за ограничения удалённого
`git archive` на SHA-коммиты; каждый файл всё равно принимается только по
ожидаемым размеру и SHA-256 из каталога. Изменение байтов в ветке даёт отказ,
а не молчаливое обновление референсов.

То же при подготовке проекта на чистой машине:

```powershell
.\scripts\bootstrap.ps1 -WithReferences POSE_ATLAS,COSTUME_DB_01
# Все пулы; файлы без публичной ссылки берутся из своей копии.
.\scripts\bootstrap.ps1 -WithReferences all -ReferencesFromDir D:\backup\refs
```

Без `-WithReferences` `bootstrap` проверяет [сохранённое решение](../docs/REFERENCE_PACK_STARTUP.md):
если решения нет — выводит предложение всего атласа; если согласие уже есть —
сам продолжает загрузку. Установленный атлас и сохранённый отказ не вызывают
повторного предложения. Согласие переживает обновление проекта и смену агента
в этом checkout; на другом устройстве без личных настроек предложение появится заново.

Обновить каталог после изменений пула на машине, где он установлен:

```powershell
.\scripts\storyart.ps1 reference_packs build POSE_ATLAS
```

| Пул | Источник | Каталог |
|---|---|---|
| `POSE_ATLAS` | закрытая [Gitea проекта](https://gitea.xapct.ru/Hatzy/StoryArt-Pose-Atlas); происхождение: ai-pose-gallery / anhao | готов, все 1439 файлов одной командой |
| `COSTUME_DB_01` | [ai-costume-gallery](https://ai-costume-gallery.pages.dev/) | готов, 1407 файлов, все скачиваются |
| `PINTEREST_SKETCH` | пины Pinterest, авторы не установлены | 586 файлов, 350 скачиваются с i.pinimg.com, остальные — вырезки |
| `DRAWING_GUIDES` | уроки [@oldmanlux](https://x.com/oldmanlux) | 238 файлов, все — вырезки фрагментов |
| `OLCHAS` | работы OlchaS | 620 файлов, 222 скачиваются с Tumblr/JoyReactor |

Вырезки и файлы, у которых нет постоянной ссылки на оригинал (подписанные
ссылки DeviantArt истекают), в `files.csv` записаны без `url`. Их можно
поставить только из своей копии: `install <ПУЛ> --from-dir <папка>`; иначе
`install` сообщает `NO_SOURCE`. Недоступная ссылка даёт `DOWNLOAD_FAILED`, а
остальные файлы пула ставятся дальше. Права на перераспространение у
Pinterest не установлены, у остальных пулов — запрещены.

В `pack.json` раздел `build` задаёт список файлов маской `glob` или полем
`paths_from` (манифест пула), а ссылки — шаблоном `url_template` или
`url_sources`: ссылка из манифеста загрузок присваивается файлу только при
совпадении SHA-256, поэтому вырезка не получает ссылку на свой оригинал.
`build` убирает из копий разметки абсолютный путь рабочей папки.
Необязательный `storage.type=GIT_ARCHIVE` выбирает потоковый Git SSH вместо
пофайлового HTTPS; ссылки в `files.csv` остаются браузерными ссылками на
соответствующие оригиналы и требуют входа в закрытую Gitea.
