# Публичная коллекция OlchaS

Собрано 2026-08-01 для локального отбора референсов StoryArt. Сырьё не удаляется и не добавляется автоматически в каноническую библиотеку тел.

## Состав

- `00_RAW/` — 1047 полученных файлов: DeviantArt 722, Tumblr 236, JoyReactor 22, Safebooru 33, DTF 16, связанный аккаунт Olnya/X 18.
- `01_QUALITY_KEEP/` — 368 уникальных файлов, прошедших технический порог.
- `02_REJECTED_TECHNICAL/LOW_RES_REVIEW/` — 459 уникальных изображений пригодны для просмотра, но имеют менее 1000 px по длинной стороне или менее 0,65 Мп.
- `02_REJECTED_TECHNICAL/TOO_SMALL/` — 57 файлов ниже минимального технического порога.
- `02_REJECTED_TECHNICAL/DUPLICATES/` и `VISUAL_DUPLICATES/` — 161 точный или визуально идентичный дубль.
- `02_REJECTED_TECHNICAL/NON_ART/` — 2 служебных/тестовых файла.
- `03_CONTACT_SHEETS/` — восемь листов быстрого визуального просмотра файлов из `01_QUALITY_KEEP`.
- `COLLECTION_MANIFEST.csv` — полный технический манифест с решением, причиной, размерами, SHA-256 и перцептивным хешем.

## Источники и ограничения

- DeviantArt: обнаружено 765 публичных записей; 720 файлов получено, 45 старых CDN-ссылок отвечают 404. Из-за блокировки исходного Wix CDN загрузка выполнялась через точечный транспортный прокси images.weserv.nl с `q=100`; такие файлы не являются побитовой копией исходника.
- Tumblr: получены все 236 медиафайлов, которые отдала публичная лента `olchas.tumblr.com`.
- JoyReactor: проверены обычная страница тега и `/all`; полученные повторы сохранены в сырье и удалены только из отобранной выдачи.
- DTF: страницы-источники для 16 файлов записаны в `DTF_SOURCES.csv`.
- Закрытые Patreon-вложения, авторизация и обход платного доступа не использовались.

Технический отсев не является художественной оценкой. Старые рисунки, скетчи, туториалы и прикладные работы автора пока сохранены; следующий семантический проход можно делать отдельно по пригодности именно как референса фигуры и больших форм.
