# Типы телесных референсов StoryArt

В проекте закреплены три независимых типа. Упоминание пользователем одного из названий или алиасов выбирает соответствующую библиотеку как область первичного поиска для тела.

| Упоминание | Тип | На чём сосредоточиться | Уровень влияния |
|---|---|---|---|
| `натура`, `фотореф`, `BODY_REFERENCE_LIBRARY` | `NATURAL` | реальная анатомия, постоянные пропорции, деформация тела в позе | может быть `BODY_BUILD_TARGET` |
| `набросок`, `контур`, `лайн` | `SKETCH` | линия действия, суставы, баланс, жест, ракурс | только `POSE_SOFT` |
| `OlchaS`, `олчас` | `OLCHAS` | художественное распределение объёма, силуэт и акцент крупных форм | только `ART_BODY_SHAPE_SOFT`, `ART_POSE_SOFT`, `ART_CAMERA_SOFT` |

## Маршрутизация

Перед подбором телесных референсов передать исходную пользовательскую формулировку маршрутизатору:

```powershell
# Показывает, какие типы явно упомянуты и какие роли им разрешены.
python tools\body_reference_type_router.py resolve --text "возьми OlchaS для формы и набросок для позы" --json
```

Если ни один тип не упомянут, результат `UNRESOLVED`: нельзя молча выбирать тип только по наличию файлов. Используется уже подтверждённый выбор текущего чата либо пользователю предлагается явный выбор.

При нескольких типах роли складываются, но не смешиваются:

- `NATURAL` или утверждённый `CHARACTER_BODY` всегда побеждает конфликт реальной анатомии и постоянных пропорций;
- `OLCHAS` добавляет язык объёма и силуэта, но не становится фотографической анатомической истиной и не переносит стиль без отдельного выбора стиля;
- `SKETCH` добавляет позу и жест, но не меняет телосложение.

Реестр и алиасы хранятся в `config/body_reference_types.json`. Проверка доступности всех трёх библиотек:

```powershell
# Проверяет корни, манифесты и количество доступных записей.
python tools\body_reference_type_router.py validate
```
