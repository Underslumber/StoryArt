# Типы телесных референсов StoryArt

Общий указатель, включая новые скетчи, одежду и учебные примеры:
`docs/REFERENCE_POOLS.md`. Эти отдельные пулы не восстанавливают старый `SKETCH`.

## Текущее состояние — 2026-10-29

По прямому решению пользователя `NATURAL` отключён и сохранён в проверенном архиве,
а старая библиотека `SKETCH` отключена и удалена. Их идентификаторы и алиасы
остаются в реестре для диагностики исторических данных, но не дают права выбора,
подготовки или прикрепления источников. `OLCHAS` сохранён без изменений.
Меню подключает только действующий `active_auxiliary_type=POSE_ATLAS`.

`POSE_ATLAS` — активная замена с `selection_policy=ALL_SOURCE_IMAGES`: все1439
изображений /288 групп поз доступны для выбора. Прежние категорийные и оценочные
исключения сняты по прямому указанию автора; замечания сохранены как примечания.
Все ракурсы принадлежат своей группе и сохраняют исходные хеши. Полный маршрут:
`docs/POSE_REFERENCE_SCENARIO.md`; отчёт: `work/pose-curation-20261029/REPORT.md`.

Ниже сохранена семантика типов; она применяется только к включённым записям
реестра `config/body_reference_types.json`.

В проекте сохранены три исторических типа и новый атлас поз. Выбор доступен только для включённых типов.

| Упоминание | Тип | На чём сосредоточиться | Уровень влияния |
|---|---|---|---|
| `натура`, `фотореф` | `NATURAL` | историческая натура, архив | отключён |
| `набросок`, `контур`, `лайн` | `SKETCH` | старый скетч, удалён | отключён |
| `OlchaS`, `олчас` | `OLCHAS` | художественное распределение объёма, силуэт и акцент крупных форм | только `ART_BODY_SHAPE_SOFT`, `ART_POSE_SOFT`, `ART_CAMERA_SOFT` |
| `атлас поз`, `библиотека поз`, `POSE_ATLAS` | `POSE_ATLAS` | группа позы и все существующие ракурсы с примечаниями | `STAGING_ONLY`, мягкая поза и камера |

## Маршрутизация

Перед подбором телесных референсов передать исходную пользовательскую формулировку маршрутизатору:

```powershell
# Показывает, какие типы явно упомянуты и какие роли им разрешены.
python tools\body_reference_type_router.py resolve --text "возьми OlchaS для формы и набросок для позы" --json
```

Если ни один тип не упомянут, результат `UNRESOLVED`: нельзя молча выбирать тип только по наличию файлов. Используется уже подтверждённый выбор текущего чата либо пользователю предлагается явный выбор.

При нескольких типах роли складываются, но не смешиваются:

- `NATURAL` или утверждённый `CHARACTER_BODY` всегда побеждает конфликт реальной анатомии и постоянных пропорций;
- `OLCHAS` добавляет язык объёма и силуэта, но не становится фотографической анатомической истиной и не переносит стиль без отдельного выбора стиля;
- `SKETCH` добавляет позу и жест, но не меняет телосложение.

Реестр и алиасы хранятся в `config/body_reference_types.json`. Проверка доступности всех трёх библиотек:

```powershell
# Проверяет корни, манифесты и количество доступных записей.
python tools\body_reference_type_router.py validate
```
