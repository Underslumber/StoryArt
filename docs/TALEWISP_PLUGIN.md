# TaleWisp — дополнительный плагин для автора

Предложение для пользователя:

> Для книги и связанной базы канона можно подключить TaleWisp: он собирает
> локальную базу из книг, документов, заметок и доступных ссылок, помогает писать и передаёт StoryArt задания по сценам.
> Подключить плагин и открыть отдельную задачу TaleWisp?

Предлагайте при потребности в базе произведения, каноне или авторском стиле;
обычному запросу на изображение дополнительная установка не нужна.

## После согласия

Проверьте наличие Codex CLI, Python 3.10+, существующего TaleWisp и marketplace:

```powershell
codex plugin marketplace list --json
```

```powershell
codex plugin list --json
```

Если подходящая версия уже установлена, используйте её. Для новой установки:

```powershell
codex plugin marketplace add Underslumber/TaleWisp --ref v0.6.2 --json
```

```powershell
codex plugin add talewisp@underslumber-talewisp --json
```

Проверьте успешные JSON-квитанции и состояние после установки. Не переписывайте
другие marketplace или глобальные настройки вручную, не заменяйте другой
плагин. При конфликте одноимённого источника сначала сверяйте адрес и версию.
Системный диалог и вход в аккаунт выполняет пользователь; agent не подтверждает
их за него. Реальная ошибка CLI остаётся ошибкой, а не успешной установкой.

Если Git недоступен, используйте [ZIP и SHA-256 из релиза](https://github.com/Underslumber/TaleWisp/releases/tag/v0.6.2)
и [штатную инструкцию](https://github.com/Underslumber/TaleWisp/blob/v0.6.2/docs/INSTALL.md).
Агент скачивает, проверяет и распаковывает в отдельный каталог, затем подключает
этот каталог как локальный marketplace и выполняет ту же установку.

## Новая задача и локальная база

С согласия пользователя создайте отдельную задачу TaleWisp через Codex
`create_thread`, предварительно найдя проект с `list_projects`. Если проекта
автора ещё нет, создайте отдельную projectless-задачу с понятным каталогом.
Используйте реальный ID из ответа; незавершённый `clientThreadId` не является
готовым `threadId`. Текущий StoryArt-чат не может загрузить новый плагин задним
числом. После запуска проверьте фактическое наличие навыков и MCP-инструментов.
Если reload требуется, скажите об этом; не обещайте готовую работу до загрузки.

Передайте только согласованные задачу и локальный путь. Не копируйте личную базу,
профиль стиля или исходные книги в StoryArt. Пользователь передаёт книги, документы, заметки или ссылки в
TaleWisp или явно предоставляет локальные пути. TaleWisp спрашивает псевдоним
до чтения и создания авторской папки, затем разворачивает базу своим механизмом.
Прямые адаптеры читают FB2, TXT, Markdown, HTML, DOCX и EPUB. Для PDF,
облачных источников, сканов и медиа TaleWisp использует доступное извлечение
и проверенный локальный снимок с происхождением и полнотой. Неполное
извлечение блокирует завершение; справочные заметки не превращаются в сюжет.
Пустая структура и установленный плагин не являются готовой базой.

Разработка плагина — в [GitHub](https://github.com/Underslumber/TaleWisp);
работа автора — через плагин и собственное локальное хранилище.
Существующий сюжет, канон, профиль стиля и настройки генерации StoryArt сохраняются.
