# Референсы после установки и обновления StoryArt

SODABABYX поставляется прямо в Git: 45 оригинальных листов, 273 одиночных
референса, 36 тематических коллажей, альбомы и манифесты с происхождением,
метками пола и SHA-256. После `git pull` они уже находятся в
`SODABABYX_SOURCE_COLLECTION`. Кадры тестовых генераций в этот набор не входят.

## Обновить каталоги и собрать базу для ориентации

В корне полученного checkout выполнить:

```powershell
.\scripts\update-references.ps1
```

Команда устанавливает поставляемые текстовые каталоги, сохраняет отличающиеся
локальные метаданные и пересобирает базу поиска с коллажами. Другие изображения
без явного `-All` или `-Pools` не скачиваются. Нужны Python с зависимостями из
`requirements-dev.txt`; на чистой машине их устанавливает `scripts/bootstrap.ps1`.
Обычный bootstrap также устанавливает каталоги и собирает эту базу.

Эквивалентные отдельные шаги:

```powershell
.\scripts\storyart.ps1 reference_packs metadata --all
```

```powershell
.\scripts\storyart.ps1 reference_knowledge build
```

Получаются `work/reference-knowledge-20261113/DATABASE.json`,
`references.sqlite3`, `index.html` и `collages/`. Дата в имени — стабильный путь
совместимости, а не ограничение на дату содержимого. На другой машине база
собирается заново из её checkout; готовая база с путями старой машины не нужна.
Без необязательных изображений каталоги доступны текстом, а отсутствующие
изображения не разрешены к просмотру или вложению. После установки изображений,
изменения манифестов или обновления кода выполнить сборку снова.
`MISSING`/`STALE` означает необходимость сборки, а не разрешение пропустить её.

## Установить все остальные пулы

```powershell
.\scripts\update-references.ps1 -All
```

Если есть предыдущая полная копия проекта, одна команда восстанавливает из неё
в том числе вырезки, для которых нет отдельного сетевого URL:

```powershell
.\scripts\update-references.ps1 -All -FromDir D:\backup\StoryArt
```

`-FromDir` принимает полный checkout с прежней структурой каталогов; для
отдельного пула также можно передать его корневую папку. Копирование и загрузка
проверяют SHA-256, существующие совпадающие файлы сохраняются. Команда не меняет
визуальные допуски или права доступа и возвращает код 1 при неполной установке.

| Пул | Где получить | Условия полного восстановления |
|---|---|---|
| SODABABYX | [@sodababyx](https://x.com/sodababyx); точные посты и media URL в `SODABABYX_SOURCE_COLLECTION/SOURCE_MANIFEST.json` | Все 354 изображения уже в Git; 45 originals + 273 singles + 36 коллажей |
| POSE_ATLAS | [Закрытый атлас проекта в Gitea](https://gitea.xapct.ru/Hatzy/StoryArt-Pose-Atlas) | 1439 PNG, доступ учётной записи по SSH; ключи и токены не поставляются |
| COSTUME_DB_01 | [ai-costume-gallery](https://ai-costume-gallery.pages.dev/) | 1407 прямых ссылок в каталоге |
| PINTEREST_SKETCH | Точные pin/media URL в `reference_packs/PINTEREST_SKETCH/metadata/ready/manifest.json` и `files.csv` | 350 из 586 файлов имеют прямой URL; остальные 236 вырезок — из своей копии |
| DRAWING_GUIDES | [@oldmanlux](https://x.com/oldmanlux); post URL и границы фрагментов в metadata | 238 вырезок — из своей копии; ссылка на пост не равна готовому фрагменту |
| OLCHAS | [OlchaS](https://www.deviantart.com/olchas); точные источники в metadata | 222 из 620 имеют прямой URL; остальные 398 — из своей копии, подписанные ссылки могут истечь |

Для каждого пула `reference_packs/<POOL>/pack.json` описывает источник и условия,
`files.csv` — относительный путь, размер, SHA-256 и доступный URL.
Авторство и ограничения источников сохраняются. Публикация каталога не выдаётся
за разрешение перераспространять остальные изображения.

Сейчас **872 файла остальных пулов не имеют прямого download URL**. Полная
сетевая установка только по ссылкам для них невозможна: нужен `-FromDir` с
собственной копией. При `NO_SOURCE`, `DOWNLOAD_FAILED` или `HASH_MISMATCH`
установщик сообщает неполный результат; скачанные корректные файлы остаются для
повторного запуска. Недоступный файл не заменяется похожим изображением.

Проверка установленных байтов:

```powershell
.\scripts\storyart.ps1 reference_packs verify
```

## Пользоваться базой

Начать с `reference_knowledge overview`, затем узкого `search` по теме и полу.
Прочитать описание, ограничения и недостающие проверки; по тематическому
коллажу выбрать номер, открыть только выбранный оригинал и сравнить его с ТЗ.
`show` даёт карточку, `set` сохраняет набор кандидатов. Коллаж не является
вложением для генератора, набор кандидатов не является утверждением источников.

Полные команды, поля карточки, просмотр в браузере и переход к штатному
`select`/`prepare-generation`: [Как ориентироваться и выбирать](REFERENCE_KNOWLEDGE.md).
