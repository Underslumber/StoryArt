# Единый каталог референсов

Сверено 2026-10-29 с последними чатами «Найти референсы поз для рисования»,
«Изучи пост и скачай референсы одежды» и действующими манифестами.

## Единые категории

Главный каталог объединяет материалы **по назначению**, независимо от сайта
или чата, где они найдены. Источник остаётся фильтром происхождения.
Один файл может входить в несколько подходящих разделов без копирования.

| Раздел | Что объединяется |
|---|---|
| Позы и действия | Ракурсы атласа и скетчи действий; бой, магия, оружие и боевые искусства — дополнительные теги. |
| Кисти, пальцы и жесты | Жестовые скетчи и правильные учебные фрагменты кистей. |
| Групповые композиции | Взаимодействия нескольких фигур и групповые листы с сохранением состава. |
| Животные | Скетчи животных и взаимодействий с ними. |
| Одежда | Комплекты нарядов и относящиеся к одежде чистые примеры. |
| Аксессуары | Объекты и детали аксессуаров по текущей исправленной разметке; тело не становится аксессуаром. |
| Ткани и посадка | Драпировка, складки и поведение ткани. |
| Анатомия | Правильные примеры строения и движения тела. |
| Лицо и выражения | Мимика и конструкция лица. |
| Волосы | Причёски и построение волос. |
| Свет и цвет | Освещение, тон и цветовые приёмы. |
| Техника рисунка | Остальные проверенные учебные приёмы. |

Актуальные количества и фильтры строит `reference_pool_manager categories`;
они не суммируются как уникальные файлы, если разделы пересекаются.
Каталог: `work/reference-pools-20261029/index.html`.

Комплект одежды с сумкой не выдаётся за отдельный вырезанный референс сумки.
Лист с несколькими позами не превращается автоматически в многовидовую группу
одной позы. Описания и теги наследуются из действующей разметки источников;
категоризация не означает новую визуальную приёмку всех изображений.

Это четыре отдельных набора, а не один пул взаимозаменяемых изображений.
Их размеры нельзя выдавать за количество уникальных поз: один лист может
содержать много изображений, а вырезки имеют родительский источник.
В исследовательском архиве учебной коллекции — 1813 уникальных исходных
изображений. Архив и рабочие 238 карточек не складываются как независимые наборы.
Сбор этого архива остановлен по решению пользователя; видео не обрабатываются.

## Общий рабочий маршрут

Реестры: `config/reference_categories.json` и `config/reference_pools.json`.
Менеджер читает действующие манифесты,
сохраняет исходные ID, категории, теги, родительские связи и условия источника.
Он не копирует изображения в старую удалённую библиотеку и не смешивает
Pinterest со всеми доступными ракурсами атласа.

```text
ТЗ и выбор пользователя
  -> подходящая категория и узкая роль
  -> общий поиск по всем источникам, названиям, тегам и метаданным
  -> выбранный ID + текущий файл/хеш + происхождение
  -> кандидат с честными замечаниями и статусом
  -> штатная подготовка конкретного запроса / проверка субъекта и роли
  -> физические вложения в exact call -> генерация -> QA
```

```powershell
.\scripts\storyart.ps1 reference_pool_manager categories
```

```powershell
.\scripts\storyart.ps1 reference_pool_manager search --category POSE_ACTION --tag COMBAT --subject MALE
```

Все 1439 изображений атласа остаются доступными независимо от категории и
прежней оценки. Остальные наборы сохраняют свои согласованные границы:
фото не включены в Pinterest-подборку; неверные и перегруженные учебные примеры
остаются в исследовательском архиве по отдельному решению пользователя.

Для Pinterest родительский лист и дочерние фрагменты не означают ракурсы одной
позы. Групповая сцена сохраняется целиком и отдельно от одиночного персонажа.
Кисть с неизвестным полом не получает выдуманную мужскую метку. Непроверенная
маркировка не превращается в PASS. Метаданные остаются доступны для поиска;
перед показом/прикреплением источника применяются требования его роли.

Экспорт кандидата не утверждает новую одежду, предмет, тело или личность и не
заменяет `prepare-generation`. Для одежды и аксессуаров действуют существующие
item/wardrobe-процессы; учебные советы используются как вопросы к плану и QA.
Права и происхождение каждого источника сохраняются отдельно. Публикация
локальной коллекции не разрешена этим подключением.

Для жестов, групповых листов и деталей выбор сохраняется как кандидат с
метаданными и честным статусом требуемой классификации/проверки роли. Такой
кандидат сохраняет родительские связи и теги, но не содержит разрешения
прикреплять непроверенное изображение к генератору. Запись не исчезает из
категории и не заменяется произвольной одиночной позой.
