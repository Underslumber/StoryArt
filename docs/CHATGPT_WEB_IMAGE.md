# Веб-генерация через отдельного агента

При явном запросе «сгенерируй через Web/ChatGPT Web» StoryArt передаёт готовое
ТЗ агенту `web_image`. Подготовка персонажа, стиля, источников, точного вызова и
визуальная приёмка остаются у основного агента в сценарии StoryArt. Встроенный
маршрут сохраняется для запросов, в которых Web не выбран.

## После скачивания проекта

В поставке находятся проектный агент, навык, настройщик, зафиксированные
зависимости Oracle, исправления генерации/скачивания и исходник скрытого
Windows-процесса. Соседний проект Web Advisor для работы не нужен.

Настройку выполняет основной агент. Пользователю остаётся:

1. Войти в свою учётную запись ChatGPT в локальном профиле интеграции.
2. Создать отдельный проект ChatGPT и сообщить его ссылку для привязки.

Привязка сохраняется в `config/chatgpt_web_image.local.json`, окружение —
в `config/chatgpt_web_image.runtime.local.json`. Эти файлы, профиль браузера,
сессии и изображения не входят в Git или переносимый архив. Без привязки
отправка запрещена; запасного перехода в главный чат нет.

## Настройка

Основной агент запускает из корня проекта:

```powershell
.\scripts\setup-web-image.ps1
```

Диагностика без запуска браузера:

```powershell
.\scripts\setup-web-image.ps1 -CheckOnly
```

Привязка после получения ссылки на созданный пользователем проект:

```powershell
.\scripts\setup-web-image.ps1 -ProjectUrl "<ссылка на ваш проект ChatGPT>" -ProjectName "Генерация артов"
```

Настройщик использует локальные или предоставленные Codex пути Python/Node,
устанавливает зависимости, проверяет и применяет комплект исправлений Oracle,
собирает Windows broker и регистрирует агента. Повторный запуск проверяет
существующую установку. Личные настройки Codex не заменяются. Наличие профиля
не доказывает вход: doctor сообщает `NOT_CHECKED`; реальный Oracle проверяет
авторизацию перед отправкой.

Вход — отдельное действие человека. Следующая команда открывает окно только
по его явной просьбе; при генерации вызывать её автоматически запрещено:

```powershell
.\scripts\setup-web-image.ps1 -Login
```

Для общей подготовки есть `scripts/bootstrap.ps1 -WebImages`. Новые чаты Codex
загружают роль из `.codex/agents/web_image.toml`; исходный шаблон —
`config/web_image_agent.toml`.

## Итоговое ТЗ

Основной агент сохраняет полный окончательный контракт в UTF-8-файл внутри
единственной папки текущего запроса. После точного вызова и EXECUTION_STARTED
он подготавливает Web journal через `chatgpt_web_image prepare`. Journal
содержит неизменённый промпт и физические референсы с хешами.

```powershell
.\scripts\storyart.ps1 chatgpt_web_image_handoff create "<папка запроса>\web.json" --final-spec "<папка запроса>\final-spec.md"
```

Команда создаёт `<имя journal>.web-image-packet.json` и штатный handoff роли
`WEB_IMAGE` в `ORCHESTRATION_HANDOFFS`. Пакет связывает полное итоговое ТЗ,
промпт, запреты, выбранные референсы, попытку, выходной путь и Web-проект.
Для следующего этапа/правки используются новые journal и файл ТЗ; прежние
не перезаписываются.

Основной агент передаёт `agent_prompt` одному агенту типа `web_image` без
истории переписки. Тот проверяет пакет перед исполнением:

```powershell
.\scripts\storyart.ps1 chatgpt_web_image_handoff check "<путь пакета>"
```

Он выполняет `chatgpt_web_image run`, продолжает `status/result` той же операции
и возвращает оригинал, SHA-256, сессию и квитанцию. Основной агент затем
смотрит изображение, выполняет QA/регистрацию, доставляет результат и закрывает
guard. Web-агент сам не объявляет сцену принятой и не меняет ТЗ или источники.

## Исполнение и восстановление

В Windows генерация работает на неактивном desktop без переключения рабочего
стола пользователя. Обычный внутренний Chrome допустим для совместимости,
но видимого окна генерации и foreground fallback нет. Если границу изоляции
подтвердить нельзя, процесс не запускается. Режим уже отправленной операции
не меняется при восстановлении.

Oracle использует браузерный маршрут и штатный Download. Копирование cookies
и авторизации, приватные HTTP-вызовы из кода, ручное управление браузером из
чата, встроенный/API/платный fallback и обход Cloudflare запрещены. CAPTCHA,
реальный отказ платформы и отсутствующая авторизация остаются внешними
границами; настройщик не обходит их.

Journal отмечается UNKNOWN до отправки и сохраняет исходную сессию. Тайм-аут
не разрешает повторный промпт. RUNNING/UNKNOWN продолжаются через ту же
операцию; ошибки и квитанции не стираются. Восстановление доказывает исходную
вкладку, полный промпт и соответствующий ответ перед скачиванием. Снимок
страницы, текст или копия входного файла не считаются результатом генерации.

## Проверка поставки

Архив создаётся из разрешённых исходников и содержит manifest с хешами.
Проверки выполняются в другой папке без Web Advisor, персональных настроек,
логина и веб-проекта: установка/doctor, сборка broker, целостность Oracle,
регистрация роли, передача ТЗ и mocked native download. Настройка не создаёт
тестовые изображения в ChatGPT. Эти проверки не утверждают, что другой
пользователь уже авторизован или что платформа никогда не потребует CAPTCHA.

Размещение роли соответствует [официальной схеме custom agents](https://learn.chatgpt.com/docs/agent-configuration/subagents).
