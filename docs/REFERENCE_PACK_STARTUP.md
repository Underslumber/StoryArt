# Атлас поз при запуске и обновлении StoryArt

Это общий вход для любого ИИ-агента, который работает с проектом, независимо
от его модели и приложения. На первой подготовке или после обновления проекта
агент сам проверяет атлас:

```powershell
.\scripts\storyart.ps1 reference_packs startup POSE_ATLAS --apply
```

Команда выдаёт JSON с `action`. Без сохранённого согласия она не скачивает
изображения. Если согласие уже записано, она сама продолжает установку всего
атласа; повторный вопрос пользователю запрещён.

| action | Действие агента |
|---|---|
| `READY` | Всё установлено; ничего не предлагать. |
| `OFFER_DOWNLOAD` | Один раз показать пользователю поле `question`: скачать весь атлас, все 1439 PNG / 288 поз, около 638 МиБ. |
| `DECLINED` | Отказ сохранён; не предлагать снова при каждом запуске или обновлении. Новая явная просьба пользователя может заменить решение. |
| `DOWNLOAD_REQUIRED` | Согласие уже есть; выполнить ту же команду с `--apply`, без вопроса. |
| `RETRY_REQUIRED` | Загрузка не завершилась; согласие сохранено. Установить причину доступа/сети, продолжить разрешённую загрузку без нового согласования. |

После явного согласия агент сразу записывает его и скачивает **весь атлас**:

```powershell
.\scripts\storyart.ps1 reference_packs startup POSE_ATLAS --decision accepted --apply
```

После отказа агент сохраняет `--decision declined`. Если согласие уже есть
в текущем чате или пользователь прямо попросил скачать весь атлас, агент
сразу использует `accepted --apply`, не показывает предложение ещё раз.
Обычный `reference_packs install POSE_ATLAS` тоже сохраняет согласие до начала
передачи, поэтому обрыв не приводит к повторному вопросу.

Решение хранится в `.local/reference-pack-consent.json`: переживает смену
агента, перезапуск и обновление этого checkout. Оно не включается в Git и не
считается чужим согласием на другом устройстве. На новом устройстве без
сохранённых настроек предложение появится один раз. Перенос личных настроек
не требуется для получения предложения; SSH-ключи и доступ к закрытой Gitea
не распространяются вместе с проектом. При недостающем доступе агент просит
только необходимое для входа, не спрашивает согласие на скачивание повторно,
не создаёт новые права или пароли и не переключает источник.

Агент выполняет команды сам. Не требовать от пользователя скачивать файлы,
создавать папки или запускать PowerShell. Скачивание не выбирает стиль и не
утверждает референсы для генерации. Ранее проверенный механизм полной
загрузки и SHA-256 описан в `reference_packs/README.md`.

`bootstrap.ps1` выполняет эту проверку и добавляет ссылку на этот документ
в существующий `AGENTS.md`, сохраняя остальные инструкции. На агенте без
поддержки `AGENTS.md` входом служит `README.md` и этот документ. Следование
инструкциям стороннего агента требует его доступа к файлам и shell проекта.
