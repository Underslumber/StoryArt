# Атлас поз — только по запросу

По последнему решению пользователя StoryArt **не предлагает скачивание поз и
не запускает загрузку** при открытии, подготовке или обновлении проекта.
Это действует для любого агента и нового устройства. Ранее сохранённое
согласие также не запускает скачивание автоматически.

Если пользователь сам просит скачать атлас, агент выполняет загрузку целиком:

```powershell
.\scripts\storyart.ps1 reference_packs install POSE_ATLAS
```

Скачиваются все 1439 PNG / 288 поз. Пользователю не нужно выбирать ракурсы,
перекладывать файлы или запускать команды. Правильные локальные файлы сохраняются;
размер и SHA-256 проверяются до установки. Если пользователь явно просит
продолжить прерванную загрузку, агент запускает ту же команду без повторного
предложения скачать.

Gitea остаётся со входом. Для текущего Git SSH транспорта нужен существующий
доступ к хранилищу; детали в `reference_packs/README.md`. Не создавать доступы
и не менять авторизацию в отсутствие соответствующего поручения.

Команда `reference_packs startup POSE_ATLAS --apply` оставлена для совместимости:
она сообщает `READY`, `DECLINED` или `ON_REQUEST` без поля `question` и ничего
не скачивает. Даже сохранённое `accepted` не запускает загрузку само по себе.
Явный `--decision accepted --apply` может использоваться агентом только при
текущем запросе пользователя на скачивание. Согласие хранится локально и не
публикуется в Git.

`bootstrap.ps1` сохраняет пользовательский `AGENTS.md`, обновляет только свой
управляемый блок и убирает из него прежнее автоматическое предложение. Для
агентов без поддержки `AGENTS.md` действует то же правило в `README.md`.
